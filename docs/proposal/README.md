# Пропоузал проєкту

Вихідний код [proposal.pdf](../../proposal.pdf), поданого 20.09.2026.

- `main.tex` — текст пропоузалу;
- `references.bib` — джерела.

Збирається офіційним шаблоном курсу
[ucu-ai-course/project-proposal-template](https://github.com/ucu-ai-course/project-proposal-template):
покладіть ці два файли поруч із `ucuproposal.cls` із шаблону (клас у репозиторій не копіюємо) і
зберіть XeLaTeX + Biber, наприклад в Overleaf або `latexmk`.
